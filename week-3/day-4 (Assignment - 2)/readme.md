## PySpark DataFrame Basics

### Topics Covered

- select()
- filter() / where()
- withColumn()
- withColumnRenamed()

### Learning Outcomes

- Select required columns from DataFrames.
- Filter records using conditions.
- Create derived columns.
- Rename existing columns.
- Remove unwanted columns.

### Conclusion

This session established the foundation of DataFrame operations in PySpark. By learning how to select, filter, modify, rename, and remove columns, learners gained the essential skills required to perform basic data manipulation and preparation tasks in real-world projects.
