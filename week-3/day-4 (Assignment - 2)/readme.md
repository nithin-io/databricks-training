# 📅 Week 3 - Day 4

## 📆 PySpark DataFrame Basics

### 🎯 Objective

The objective of this session is to understand the fundamental DataFrame transformation operations in PySpark. Learners will explore techniques for selecting columns, filtering records, creating new columns, renaming existing columns, and removing unwanted columns from datasets. These operations form the foundation for data manipulation and preparation in real-world data engineering projects.

---

### 📚 Topics Covered

- select()
- filter() / where()
- withColumn()
- withColumnRenamed()
- drop()

---

### 🎯 Learning Outcomes

- Select required columns from DataFrames.
- Filter records using conditions.
- Create derived columns.
- Rename existing columns.
- Remove unwanted columns.
- Build a strong foundation in DataFrame transformations.

---

### ✅ Conclusion

This session introduced the core DataFrame transformation techniques in PySpark. By practicing these operations, learners developed the essential skills required to manipulate and prepare structured datasets efficiently for analysis and reporting.
