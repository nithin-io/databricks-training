# 📅 Week 3 - Day 6

## 📆 DataFrame Combination Operations

### 🎯 Objective

The objective of this session is to understand how datasets can be combined and integrated using various DataFrame operations. Learners will work with joins, unions, schema-aware merging, and sampling techniques that are commonly used in ETL pipelines and business reporting solutions.

---

### 📚 Topics Covered

- join()
- union()
- unionByName()
- limit()
- sample()

---

### 🎯 Learning Outcomes

- Combine multiple datasets.
- Perform different join operations.
- Merge DataFrames with varying schemas.
- Retrieve limited records.
- Generate sample datasets.
- Understand data integration concepts.

---

### ✅ Conclusion

This session introduced techniques for combining datasets from multiple sources. Learners developed the ability to integrate and process data efficiently, an essential requirement in real-world data engineering workflows.
